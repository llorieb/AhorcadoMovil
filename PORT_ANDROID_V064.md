# Ahorcado Android v0.6.4

Base: v0.6.3.

## Preferencias más compactas

El overlay de Preferencias conserva el mismo diseño y el ScrollView,
pero se ajustó para que en una pantalla móvil normal puedan verse
simultáneamente las cuatro categorías y los cuatro tiempos.

Cambios:
- Menor padding vertical de la tarjeta.
- Encabezado apenas más compacto.
- Menor separación entre secciones.
- RadioButtons de 42dp de alto.
- Menor margen antes de la botonera.
- Altura máxima del overlay reducida de 640dp a 610dp.

El ScrollView permanece como respaldo para pantallas con menor altura útil.

No se modificó ninguna otra funcionalidad, overlay, audio, icono o lógica.
