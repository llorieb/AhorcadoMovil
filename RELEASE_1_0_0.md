# Ahorcado Android 1.0.0

Final release promoted from 1.0.0-rc4.

## Frozen identity
- applicationId: `com.llorieb.ahorcado`
- versionCode: 30
- versionName: `1.0.0`

## Release scope
This final release is functionally identical to RC4.

No gameplay, UI, responsive behavior, corpus, language support, audio,
permissions, splash, launcher icon, settings or navigation behavior changed
during the promotion from RC4 to 1.0.0.

## Supported behavior
- Spanish and English.
- English fallback for unsupported device languages.
- Phone normal mode.
- Phone compact-height mode.
- Wide/tablet mode.
- Wide/tablet compact-height mode.
- Scroll fallback for constrained landscape phone windows.
- Portrait and landscape tablet layouts verified during RC testing.
